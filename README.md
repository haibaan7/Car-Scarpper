
# TIC Vehicle Auction Bot

Private Telegram vehicle auction listing bot.

## Features

- Receives auction listing URLs.
- Receives vehicle photos.
- Extracts vehicle information from auction pages.
- Posts formatted listings to Telegram.
- Supports Telegram group topics.
- Prevents duplicate listings.
- Uses Cloudflare Workers and D1 Database.

## Platform

- GitHub
- Cloudflare Workers
- Cloudflare D1
- Telegram Bot API
